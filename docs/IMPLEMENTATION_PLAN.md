# Implementation plan

1. Audit the empty upstream repository and inspect the four supplied HEIC logos. Preserve original brand assets and publish browser-compatible copies.
2. Create four independently deployable Next.js / TypeScript / Tailwind applications in an npm-workspace monorepo. Share technical utilities and accessible primitives; keep art direction, homepages, and business copy separate.
3. Build each homepage and supporting about, service, individual service, gallery, area, FAQ, contact, and privacy pages. Mark service proposals and illustrative photography honestly.
4. Add validated server-side estimate delivery with a configurable provider, spam controls, and explicit unavailable states when not configured. Add per-app business settings, metadata, sitemap, and robots.
5. Run builds, type checks, lint, meaningful delivery tests, and browser checks at desktop, tablet, and mobile widths. Independently review accessibility, design, and SEO, and fix findings.
6. Document deployment and owner-supplied settings, and save tested installation/startup instructions in the cloud environment draft.

Owner facts (phone, email, live domains, confirmed services, project photographs, and operating details) remain unset until supplied. No invented reviews, history, credentials, or projects.
